# Alkokab Tech Solutions

This project is built with [TanStack Start](https://tanstack.com/start) (React + Vite) and is fully self-hosted.

## Development

Requires Node.js 22.12+ and npm.

```sh
npm install
npm run dev
```

The dev server runs on http://localhost:8080.

## Build

```sh
npm run build
npm run preview
```

Production server output is emitted by Nitro and can be started with:

```sh
npm run build
node .output/server/index.mjs
```
